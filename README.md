# GRE 词境 · Lexi Atlas

[打开在线网站](https://paranoiawang0818.github.io/gre-vocabulary-trainer/)

一个无需账号和 AI 接口即可使用的 GRE 学习网站。采用纯前端实现，学习进度保存在当前浏览器中。

## 学习功能

- 每日 15 词，共 101 天。依次完成翻卡、分组强化、连线纠错、释义复盘与打卡。
- 主动回忆、释义选择和拼写测验。支持今日词、到期词、错词、收藏、指定 List 和自选词。
- 三栏单词星图，支持搜索、筛选、多选测验、笔记、词汇连接与可调整布局。
- 沉浸星图，支持拖动和调整目录、详情浮窗。
- 4 篇预置语境短文，支持查词侧栏、译文、连续逐句朗读和读后测验。
- 四季列车伴读，支持单词与文章播放列表、播放间隔、语音和环境音设置。
- 本机学习档案、复习计划、学习日历、使用报告和 JSON 备份。

GRE 核心词库包含 31 个 List、1,515 条记录和 1,512 个不同拼写。相同拼写的不同条目保留各自释义与学习进度。词汇连接根据中文释义重合、拼写相近或同组位置计算，不代表词典中的同义词或词源关系。

## 本地运行

Mac 可双击 `启动词境.command`，或在项目目录运行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:4173/>。无需安装 npm 依赖。

不同域名、端口和浏览器使用各自的本地存储。将本地进度迁移到在线网站时，请先在“设置 → 数据与档案”导出 JSON，再到在线网站导入。导入或重置前，网站会下载当前档案的恢复备份。

本机档案不提供云端认证或同步。系统语音的音色和可用性取决于设备。AI 接口尚未接入。

## 检查与发布

```bash
node scripts/qa-app.mjs
node scripts/build-pages.mjs
```

第一条命令检查词库、题目、复习规则和备份兼容性。第二条命令按固定文件清单生成 `dist/`，只包含网站运行所需的页面、脚本、样式、媒体与许可文件。

推送到 `main` 后，GitHub Actions 会执行检查并将 `dist/` 部署到 GitHub Pages。原始表格、本地学习记录、备份和验收资料不进入发布包。仓库保留网站运行所需的词汇数据；静态网站中的这些数据可以被访问者读取。

## 文件说明

- `app.js`：界面、路由、学习会话与档案。
- `core.js`：关系计算、测验选项、日期、复习规则与备份校验。
- `styles.css`：主题、布局与响应式样式。
- `words-data.js`：GRE 核心词库。
- `reading-data.js`：预置原创短文与目标词。
- `ambient-audio.js`：本地环境音合成。
- `assets/ambient/`：四季伴读媒体。

界面与交互参考 [orionsheep/wordlink](https://github.com/orionsheep/wordlink)，网站页脚也保留参考链接。伴读媒体沿用该项目的 MIT 授权文件，详见 [媒体说明](assets/ambient/NOTICE.md) 与 [许可文本](docs/WordLink-MIT-LICENSE.txt)。
