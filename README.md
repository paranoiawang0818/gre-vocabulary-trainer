# GRE 词境

这是一个由 `Nigel的GRE核心单词总结_副本.xlsx` 生成的纯前端背词网站，共 1,515 词、101 天。

## 使用

直接双击 `index.html` 即可使用。若浏览器限制本地脚本，可在本文件夹启动任意静态服务器，例如：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

学习进度、错词、打卡和笔记会保存在当前浏览器的 `localStorage` 中。建议在“数据设置”中定期导出 JSON 备份。

从旧版 25 词计划首次加载本版本时，网站会自动清空旧进度并以 15 词计划重新开始。

## 核心流程

1. 每天 15 词闪卡：正面英文，翻面看中文，判断熟悉或不熟悉。
2. 不熟词按每组最多 5 词强化：记忆钩子、语音、私人笔记。
3. 每组连线测试；错词进入下一轮，直到全部正确。
4. 当天全部单词进行 GRE 式语境选择复盘。
5. 问题词进入次日复习队列，并再次通过记忆钩子与循环连线清除。
6. 完成当天复盘后自动点亮打卡灯。

记忆提示按每个单词分别生成并固化保存，内容结合该词的拼写、构词线索和中文释义；它们是记忆联想，不作为严格词源结论。复盘题干优先使用英文词典释义或英文例句，不显示中文提示。
